Сохраняет выделенный или скопированный текст в Markdown-файл одним нажатием клавиш на macOS. Имя файла — дата и время: `вт.21.08.2026 13.22.md`.

Работает через Apple Shortcuts, поэтому доступно из любого приложения: Safari, Notes, Mail, Telegram, PDF-читалки. Без зависимостей — только стандартная библиотека Python 3, который в macOS уже есть.

```
Выделил текст  ──┐
                 ├──▶  ⌥⌘M  ──▶  VAULT/вт.21.08.2026 13.22.md
Скопировал     ──┘
```

## Зачем это нужно

Наивный вариант «сохранить выделение в файл» на macOS выглядит как три строки shell:

```zsh
mkdir -p "$DIR"
NAME=$(date "+%a.%d.%m.%Y %H.%M")
cat > "$DIR/$NAME.md"
```

Он ломается тремя способами, и все три встречаются в обычной работе.

**Пустой файл при копировании из Safari.** Safari и Google AI кладут в буфер несколько представлений одного текста сразу. Вот что реально лежит в буфере после копирования ответа Google AI:

```
«class HTML», 22065, «class utf8», 5492, «class ut16», 6560, string, 0, Unicode text, 6558
```

Представление `string` — нулевой длины, и `pbpaste` берёт именно его. Файл создаётся, но он пустой. `clip2md` спрашивает буфер через AppleScript (`the clipboard as text`), и macOS отдаёт текстовое представление.

**HTML вместо текста.** Если ярлык принимает «Веб-страницы Safari», в скрипт приходит разметка. stdin при этом непустой, поэтому проверка «если пусто — возьми буфер» не спасает, и в заметку уезжает `<div><p>…`. `clip2md` распознаёт разметку и конвертирует её в Markdown.

**Битое имя файла.** Оболочка внутри песочницы Shortcuts запускается без UTF-8 локали, и системный `date` портит первый байт дня недели. В отладочном логе имя выглядело так:

```
NAME: \M-^Aб.22.08.2026 21.03
```

`clip2md` ставит локаль явно из Python и получает нормальные `сб`, `вт`, `вс`.

## Что делает с HTML

Разметка превращается в читаемый Markdown, а не в кашу из тегов:

| Вход | Выход |
|---|---|
| `<h2>Заголовок</h2>` | `## Заголовок` |
| `<li>пункт</li>` | `- пункт` |
| `<strong>жирный</strong>` | `**жирный**` |
| `<em>курсив</em>` | `*курсив*` |
| `<code>cmd</code>` | `` `cmd` `` |
| `&nbsp;` `&mdash;` `&lt;` | ` ` `—` `<` |
| `<style>`, `<script>` | выбрасываются |

Обычный текст не трогается: строка «если a < b» останется собой, а не уедет в HTML-парсер. Тег распознаётся по закрытому списку имён, а не по любому символу `<`.

## Установка

```bash
git clone https://github.com/andreevgeny/clip2md.git
cd clip2md
mkdir -p ~/bin && cp clip2md.py ~/bin/ && chmod +x ~/bin/clip2md.py
```

Проверка без Shortcuts — скопируйте что-нибудь и запустите:

```bash
python3 ~/bin/clip2md.py
```

Скрипт напечатает путь созданного файла.

## Настройка папки

По умолчанию используется путь iCloud-хранилища Obsidian. Свой путь задаётся двумя способами:

```bash
# переменной окружения
export CLIP2MD_DIR="$HOME/Documents/Notes"

# или флагом
python3 ~/bin/clip2md.py --dir "$HOME/Documents/Notes"
```

Найти путь своего хранилища Obsidian можно так:

```bash
ls ~/Library/Mobile\ Documents/iCloud~md~obsidian/Documents/
```

Осторожно: в `~/Documents` может лежать папка-пустышка с тем же именем `iCloud~md~obsidian`. Настоящее хранилище — в `~/Library/Mobile Documents`. Запись в пустышку и была одной из причин, по которой заметки «сохранялись», но не появлялись в Obsidian.

## Ярлык в Apple Shortcuts

1. Быстрые команды → новая команда.
2. Шапка ⓘ: включить **Использовать как быстрое действие** и **Меню «Службы»**.
3. **Принимать:** `Текст`, `Форматированный текст`, `Веб-страницы Safari`, `Статьи`.
4. **Если нет входных данных:** `Получить буфер обмена`. Без этого ярлык не запускается вовсе, когда ничего не выделено — macOS останавливает его до вызова скрипта.
5. Добавить действие **Запустить сценарий оболочки**:
   - Shell: `/bin/zsh`
   - **Передать ввод: в stdin** — обязательно. При «как аргументы» скрипт не получит текст.
6. Код действия — одна строка:

```zsh
python3 "$HOME/bin/clip2md.py"
```

7. Горячая клавиша: Системные настройки → Клавиатура → Сочетания клавиш → Службы → найти команду → назначить, например `⌥⌘M`.

Теперь выделение или буфер сохраняются в заметку из любого приложения.

## Если не работает

**`Run Shell Script finished with an error`** без подробностей. Уведомление Shortcuts не показывает причину. Направьте вывод в лог и посмотрите, что там:

```zsh
python3 "$HOME/bin/clip2md.py" >> "$HOME/clip2md.log" 2>&1
```

**Ярлык не запускается по горячей клавише, когда ничего не выделено.** В шапке ⓘ пункт «Если нет входных данных» стоит в значении «Остановиться». Нужно `Получить буфер обмена`.

**Файл создаётся пустым.** Проверьте, что буфер вообще содержит текст:

```bash
osascript -e 'clipboard info'
```

Если в выводе только `«class HTML»` и `string, 0` — это тот самый случай, для которого написан скрипт. Убедитесь, что запускается `clip2md.py`, а не `cat` или `pbpaste`.

**Отказ в доступе к папке.** Системные настройки → Конфиденциальность и безопасность → Полный доступ к диску → добавить Быстрые команды (Shortcuts).

**День недели по-английски.** В системе нет русской локали. Проверка:

```bash
locale -a | grep ru_RU
```

## Тесты

```bash
python3 -m unittest discover -v
```

20 тестов, покрывают эвристику определения HTML, конвертацию, формат имени файла и запись. Регрессы из отладки на живой системе (void-тег `<meta>`, текст с `<`, `\r` от AppleScript) закреплены отдельными тестами.

## Как устроен код

Четыре шага, они же четыре блока в `main()`:

1. `read_stdin()` — сырьё от Shortcuts: текст или HTML.
2. `clean()` — разметку в Markdown, обычный текст только нормализовать.
3. `from_clipboard()` — если после чистки осталось меньше трёх значимых символов, значит выделения не было: берём буфер через AppleScript, затем `pbpaste` как резерв.
4. `save_note()` — запись файла с именем от `stamp()`.

Конвертер `HTMLToMarkdown` не строит дерево документа: идёт по потоку тегов и дописывает маркеры Markdown. Для ответа чат-бота или статьи вложенность мелкая, потока достаточно, зато нет зависимостей от `beautifulsoup4` или `html2text` — внутри песочницы Shortcuts установка пакетов недоступна.

Каждое неочевидное решение в коде объяснено комментарием: почему счётчик, а не флаг для `<script>`; почему `<meta>` в отдельном списке; почему порог три символа, а не ноль; почему в имени файла точка вместо двоеточия.
